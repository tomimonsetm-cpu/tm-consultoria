# TM Consultoría de Procesos y Automatización — Web Oficial

Repositorio oficial del sitio web estático B2B de **TM Consultoría**, firma dedicada a documentar, ordenar y automatizar procesos operativos para pymes, retail y productores agropecuarios.

El sitio está diseñado para transmitir cercanía, solidez y practicidad, actuando como un puente entre el negocio real y la tecnología.

## 🛠 Arquitectura y Stack Tecnológico

Este proyecto es un sitio web estático optimizado para cargar rápido y ser fácilmente mantenible, sin depender de frameworks complejos ni procesos de compilación (build steps).

* **HTML5 semántico:** Estructura accesible y optimizada para SEO.
* **CSS3 Vanilla:** Estilos construidos con variables nativas (`:root`) basadas estrictamente en el Manual de Marca V1.0.
* **JavaScript Vanilla:** Microinteracciones (fade-in, menú móvil) y validación del formulario de contacto.
* **Hosting:** Desplegado mediante GitHub Actions en GitHub Pages.

## 🎨 Identidad Visual (Manual de Marca V1.0)

El diseño respeta los lineamientos corporativos para evitar el "azul corporativo" genérico y abrazar tonos tierra:
* **Colores principales:** Beige/Arena (`#EFE9D9`, `#F7F4EC`), Gris Oscuro (`#2F312E`), Verde Seco (`#7A8B69`) y Terracota (`#B85A3A`).
* **Tipografías:** `Montserrat` (Títulos y jerarquía) y `Roboto` (Cuerpos de texto y legibilidad).
